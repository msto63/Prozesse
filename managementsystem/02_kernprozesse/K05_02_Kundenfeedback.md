# K05.02 Kundenfeedback einholen und bearbeiten

**Zweck:** Dieser Teilprozess beschreibt den systematischen Umgang mit Kundenfeedback jeglicher Art (Lob, Kritik, Anregungen), um die Kundenzufriedenheit zu steigern und die eigenen Prozesse und Dienstleistungen kontinuierlich zu verbessern.

**Geltungsbereich:** Der Prozess gilt für alle Kunden und alle Geschäftsbereiche.

| | |
| :--- | :--- |
| **Prozesseigner** | [Geschäftsführer Vertrieb](../rollen/R01_Geschaeftsfuehrer_Vertrieb.md) |
| **Input** | `Feedback vom Kunden (direkt, per Umfrage, aus Meetings)` |
| **Output** | `Bearbeitetes Feedback`, `Abgeleitete Verbesserungsmaßnahmen`, `Informierter Kunde` |

---

## Prozessschritte

1.  **Feedback erfassen**:
    -   Feedback kann auf verschiedenen Wegen eingehen:
        -   **Reaktiv**: Direkte Beschwerden oder Lob vom Kunden per E-Mail oder Telefon.
        -   **Proaktiv**: Geplante [Zufriedenheitsumfragen](../artefakte/A15_Zufriedenheitsumfrage.md) bei Entscheidern.
        -   **Operativ**: Kontinuierliches Feedback zu Tickets ([KPI10 Anwenderzufriedenheit](../kpis/KPI10_Anwenderzufriedenheit.md)).
        -   **Persönlich**: Feedback aus Service-Review- oder anderen Kundengesprächen.
    -   Jedes relevante Feedback wird zentral erfasst (z.B. im CRM-System), um eine Auswertung zu ermöglichen.
    -   **Verantwortlich**: [Account Manager](../rollen/R04_Account_Manager.md), [Service Delivery Manager](../rollen/R11_Service_Delivery_Manager.md)

2.  **Feedback analysieren und kategorisieren**:
    -   Das erhaltene Feedback wird analysiert und bewertet.
    -   Bei negativem Feedback oder Beschwerden wird die Ursache analysiert.
    -   **Verantwortlich**: Zuständiger Manager (Account oder Service Delivery)

3.  **Sofortmaßnahmen ergreifen (bei Beschwerden)**:
    -   Bei einer Beschwerde wird dem Kunden zeitnah eine Eingangsbestätigung gesendet.
    -   Der zuständige Manager koordiniert die notwendigen Sofortmaßnahmen zur Lösung des akuten Problems.
    -   **Verantwortlich**: Zuständiger Manager

4.  **Verbesserungsmaßnahmen definieren**:
    -   Basierend auf der Analyse werden strukturelle Verbesserungsmaßnahmen abgeleitet, um die Ursache des Feedbacks (insbesondere bei negativem Feedback) zu beheben.
    -   Diese Maßnahmen werden im Rahmen des Prozesses [F03 Kontinuierliche Verbesserung](../01_fuehrungsprozesse/F03_Kontinuierliche_Verbesserung.md) verfolgt.
    -   **Verantwortlich**: Zuständiger Manager

5.  **Rückmeldung an den Kunden**:
    -   Der Kunde erhält eine qualifizierte Rückmeldung zu seinem Feedback, insbesondere über die ergriffenen und geplanten Maßnahmen. Dies schließt den "Feedback-Loop" und zeigt dem Kunden, dass seine Meinung wertgeschätzt wird.
    -   **Verantwortlich**: Zuständiger Manager
