# U04.02 Interner IT-Support

**Zweck:** Dieser Teilprozess beschreibt die Annahme, Bearbeitung und Lösung von technischen Anfragen und Störungsmeldungen der Mitarbeiter (interne Kunden). Er dient als zentrale Anlaufstelle (Single Point of Contact) für alle IT-bezogenen Anliegen.

**Geltungsbereich:** Der Prozess umfasst alle Anfragen und Störungen, die von Mitarbeitern an die interne IT-Abteilung gemeldet werden.

| | |
| :--- | :--- |
| **Prozesseigner** | [Leiter IT](../rollen/R16_Leiter_IT.md) |
| **Input** | `IT-Anfrage oder Störungsmeldung eines Mitarbeiters` |
| **Output** | `Gelöstes Ticket`, `Zufriedener Mitarbeiter` |

---

## Prozessschritte

1.  **Anfrage erfassen und Ticket erstellen**:
    -   Mitarbeiter melden ihr Anliegen über definierte Kanäle (z.B. Ticket-System, E-Mail, Telefon).
    -   Für jedes Anliegen wird ein Ticket im internen ITSM-Tool erfasst.
    -   **Verantwortlich**: IT-Support-Mitarbeiter (oft eine dedizierte 1st-Level-Rolle oder ein [IT-Administrator](../rollen/R17_IT_Administrator.md))

2.  **Klassifizieren und Priorisieren**:
    -   Das Ticket wird kategorisiert (z.B. Störung, Anfrage, Hardware, Software) und priorisiert, um eine zeitnahe Bearbeitung kritischer Anliegen sicherzustellen.
    -   **Verantwortlich**: IT-Support-Mitarbeiter

3.  **Erstlösungsversuch**:
    -   Versuch der sofortigen Lösung des Anliegens, oft auf Basis von bekannten Lösungen aus einer internen Wissensdatenbank.
    -   **Verantwortlich**: IT-Support-Mitarbeiter

4.  **Eskalation (falls erforderlich)**:
    -   Wenn eine Erstlösung nicht möglich ist, wird das Ticket an einen spezialisierten [IT-Administrator](../rollen/R17_IT_Administrator.md) (2nd/3rd Level) mit dem entsprechenden Fachwissen weitergeleitet.
    -   **Verantwortlich**: IT-Support-Mitarbeiter

5.  **Bearbeitung und Lösung**:
    -   Der zuständige Bearbeiter analysiert das Problem und erarbeitet eine Lösung.
    -   Alle Bearbeitungsschritte werden im Ticket dokumentiert.
    -   **Verantwortlich**: Zuständiger IT-Support-Mitarbeiter / [IT-Administrator](../rollen/R17_IT_Administrator.md)

6.  **Abschluss und Rückmeldung**:
    -   Die Lösung wird dem meldenden Mitarbeiter mitgeteilt.
    -   Nach Bestätigung durch den Mitarbeiter wird das Ticket geschlossen.
    -   **Verantwortlich**: Zuständiger Bearbeiter
