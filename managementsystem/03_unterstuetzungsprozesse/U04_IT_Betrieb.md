# U04 IT-Infrastruktur & -Betrieb

**Zweck:** Dieser Prozess stellt die Bereitstellung, Wartung und Überwachung einer stabilen, sicheren und leistungsfähigen internen IT-Infrastruktur sicher. Er gewährleistet, dass alle Mitarbeiter über die notwendigen technischen Arbeitsmittel verfügen und die für die Leistungserbringung notwendigen Systeme reibungslos funktionieren.

**Geltungsbereich:** Der Prozess umfasst die gesamte interne IT-Infrastruktur, einschließlich Hardware, Software, Netzwerk und Rechenzentrumsdienste.

| | |
| :--- | :--- |
| **Prozesseigner** | [Leiter IT](../rollen/R16_Leiter_IT.md) |
| **Input** | `Hardware-Anforderung eines Mitarbeiters`, `Störungsmeldung (intern)`, `Neuer Mitarbeiter` (aus [U01](../03_unterstuetzungsprozesse/U01_Personalmanagement.md)) |
| **Output** | `Funktionierender Arbeitsplatz`, `Bereitgestellte Anwendung`, `Gelöste interne Störung`, `Sichere IT-Umgebung` |
